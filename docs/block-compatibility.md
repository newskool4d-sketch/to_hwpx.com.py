# Converter Block Compatibility Matrix

This matrix records the current block contract before new block types or parser
refactors are introduced.

| Block type | Parser producer | Required fields | COM renderer behavior | Direct HWPX renderer behavior | Fallback/error behavior | Fixture test |
|---|---|---|---|---|---|---|
| `h` | Markdown headings, HTML `h1`-`h3`, XLSX sheet title, PDF ODL headings, DOCX heading styles | `level`, `text` | Sets heading paragraph/character shape, inserts `text`, then breaks paragraph. | Level 1 title is skipped when it matches cover title; level 2 becomes a section bar; other headings become emphasized text paragraphs. | Missing fields raise through normal dict access in COM; direct path defaults missing level/text where `.get()` is used. | `tests/test_parse_contracts.py`, `tests/test_renderer_contract.py` |
| `p` | Markdown fallback paragraph, TXT fallback paragraph, HTML `p`, PDF text fallback, DOCX body paragraphs | `text` | Sets body paragraph/character shape, inserts `text`, then breaks paragraph. | Falls through to plain text paragraph when `text` is present. | Empty/missing `text` is ignored in direct path; COM requires `text`. | `tests/test_parse_contracts.py`, `tests/test_renderer_contract.py` |
| `li` | Markdown/TXT hierarchy items, HTML list items, PDF ODL lists, DOCX numbered list paragraphs | `text`, optional `depth`, `marker`, `content` | Computes hierarchy indent, inserts `text`, then breaks paragraph. | Uses `make_hierarchy_para` with depth/marker/content metadata. | Missing depth defaults to detected or 0; missing marker defaults to detected marker or `-`. | `tests/test_parse_contracts.py`, `tests/test_renderer_contract.py` |
| `table` | Markdown tables, HTML tables, CSV files, XLSX worksheets, PDF ODL tables, DOCX tables | `header`, `rows` | Creates an HWP table, sizes columns/rows, inserts header/body cell text, moves to document end, then breaks paragraph. | Builds `<hp:tbl>` XML with normalized rows and appends an empty line. | Empty table is ignored by both table builders. | `tests/test_parse_contracts.py`, `tests/test_renderer_contract.py` |
| `bq` | Markdown/HTML blockquotes, DOCX quote styles | `text` | Uses indented italic body style, inserts `text`, then breaks paragraph. | Renders as a body paragraph with `※` label. | COM requires `text`; direct path defaults missing text to empty. | `tests/test_parse_contracts.py`, `tests/test_renderer_contract.py` |
| `code` | Markdown fenced code, HTML `pre`, DOCX code styles | `text` | Uses indented code-like style, inserts `text`, then breaks paragraph. | Falls through to plain text paragraph with code text. | Empty/missing `text` is ignored in direct path; COM requires `text`. | `tests/test_parse_contracts.py`, `tests/test_renderer_contract.py` |
| `hr` | Markdown horizontal rules, DOCX horizontal styles | none | Inserts a centered line made from box-drawing characters, then breaks paragraph. | Appends an empty line. | Unknown extra fields are ignored. | `tests/test_renderer_contract.py` |
| `official_header` | Markdown/DOCX lines beginning `수신:`, `경유:`, or `제목:` | `key`, `value` | Renders a padded label and value, then breaks paragraph. | Renders as a body paragraph whose label is `key` and body is `value`. | COM requires `key` and `value`; direct path defaults missing values to empty strings. | `tests/test_parse_contracts.py`, `tests/test_renderer_contract.py` |
| unknown | Future or malformed producers | optional `text` | Ignored silently. | Renders as a plain text paragraph only when `text` is present; otherwise ignored. | This asymmetry is current behavior and must be revisited before adding new block types. | `tests/test_renderer_contract.py` |
